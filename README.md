## ストーリー概要
- 7人組アイドルグループのセンターが失踪
- 大きな箱でのワンマン直前に意味深なSNS投稿をして消息不明に
- メンバーの知り合いとして調査を依頼される（警察には出せない案件）
- 占い好きのメンバーがSNSのファン向け投稿の中にヒントを仕込んでいる
- 全員怪しく見えるが最終的に全員シロ
- 展示会に来た人だけが解ける謎がある
- 3月2日にセンターが帰還・ワンマン成功でハッピーエンド

## 導入演出の仕様
| 項目 | 内容 |
|------|------|
| デザイン | Twitter DM風 |
| 進み方 | 基本自動で流れる・選択肢の直前だけ止まる |
| 選択肢 | ストーリーには影響しないが相手の反応が変わる |
| 終わり方 | 選択肢を選んでゲーム開始→TOPへ |

---

## 演出アイデア
- 機密文書ページ → 黒背景・白文字・戻るボタンのみ
- ABOUTページの1ワードを隠しリンクにして機密ページへ
- フィクションのアクセスログをターミナル風に表示
- ブラウザのキャッシュクリア →「記録が消えた」演出として活用

## SNS運用
- グループ公式アカウントを作成（鍵垢で運用）

- 占い好きメンバーのファン向け投稿にヒントを仕込む
- 最後の意味深ツイートからnoteへ誘導（遊び方・ノンフィクション表記など）
- 展示会終了後3/2にセンター帰還のツイート
